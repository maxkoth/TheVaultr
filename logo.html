Brand · Logo System

Vaultr

Three clean, geometric symbol directions — each shown as a primary lockup, iOS app icon (both fills), wordmark, and monochrome. Wordmark set in Sora. All artwork is inline SVG; use the copy button on each concept to grab the symbol code.

Concept A · Recommended

Stacked Card

A card with a second card tucked behind it — the literal object the app is built around, plus a hint of “your collection.” The clipped corner keeps it reading as a card, not a square.
